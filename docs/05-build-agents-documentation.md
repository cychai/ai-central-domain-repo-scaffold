# 构建 Agent 文档

## 本节目标

手工建立 L0、L1、L3 的渐进式 Agent 上下文。

## 前置输入

已完成目录设计和服务读写边界。

## 为什么要做

Agent 默认上下文有限；入口过长会挤掉任务证据，入口过短又会丢失硬门禁。

## 操作步骤

编写根 AGENTS.md 的定位、边界、强制规则和稳定入口；编写 docs/AGENTS.md 索引；把架构、多仓、工作流和测试下沉。

## 关键文件解析

根入口负责路由，专题负责解释，服务仓 AGENTS.md 负责服务内部执行规则。

## 设计取舍

只生成标准 `AGENTS.md`；不要维护大小写重复入口。

## 验证命令与预期结果

运行 `python3 -m central_repo_scaffold render --config examples/domain.yaml --output /tmp/rendered-central`，对照三层文档。

## 常见错误及根因

复制服务代码说明到根入口会造成漂移；根因是没有尊重服务仓执行权威。

## 学员练习

从一个需求出发，记录 Agent 最少需要读取的文件链。

## 完成标准

根入口精简、只读边界清楚、所有链接真实存在。
