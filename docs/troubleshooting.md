# 故障排查

| 现象 | 根因 | 处理 |
| --- | --- | --- |
| `No module named yaml` | 未使用脚手架虚拟环境 | 运行 `make install`，再用 `.venv/bin/python` |
| `目标目录已存在` | 安全地拒绝覆盖 | 选择新目录或人工检查后删除旧临时目录 |
| `缺少 Git 身份` | 首次提交没有作者配置 | 由用户配置 Git 身份；工具不代配 |
| `committed HEAD` | 源仓只有 `git init` 没有提交 | 创建真实基线提交，或重新决策挂载模式 |
| 服务路径未配置 | public domain.yaml 已脱敏 | 设置 `CENTRAL_SERVICE_<ID>_PATH` |
| 分支已被占用 | 同一源仓分支绑定其他 worktree | 复用正确需求目录或选择新分支，不强删 |
| `not-executed` | 服务验证尚未运行 | 进入目标服务显式运行清单命令并记录 |

排查按输入、渲染、Git、挂载、验证五层定位，不用复制模式或强制删除掩盖根因。
